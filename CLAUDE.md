# Asistanım – geliştirici notları

Expo SDK 57 / React Native / TypeScript. Routes `src/app/` altında (Expo Router). Native davranış `app.json` config plugin'leri ile; `ios/` ve `android/` elle oluşturulmaz.

Komutlar: `npx expo start` · `npm run typecheck` · `npm run lint` · `npm test`. Bir görevi bitirmeden önce üçünü de çalıştır.

Yeni paket eklerken `npx expo install <paket>` kullan (SDK uyumlu sürüm). Expo API'leri için güncel dokümana bak: https://docs.expo.dev/versions/v57.0.0/
